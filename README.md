# wIaF — макет сайта и ЛК

Публичный демо-макет (не прод `wiaf.ru`): витрина + кабинет заказчика + кабинет исполнителя + база знаний.

**Live:** https://dantrusov10.github.io/wiaf-site/

## Локально

```bash
npm ci
npm run dev
```

Откроется http://127.0.0.1:5173/

Сборка под GitHub Pages:

```bash
VITE_BASE=/wiaf-site/ npm run build
```

## Что внутри

- Слепой аукцион 60 мин, комиссия **1% без потолка 5к**, холд = 1% ставки
- База `/help` — лайфхаки, инструкции к инструментам, инсайты кабинета (не дубль статей)
- Гид `/guide` — первый лот за 10 минут
- Кресло директора — почта отдельно от логиста
